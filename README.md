# ImgViewer

ImgViewer 是一个轻量、快速、极简主义的 Windows 图片查看器。

## 特点

- 小而轻：原生 Windows 应用。
- 快速看图：打开一张图片后，可以用方向键浏览同一文件夹中的上一张或下一张图片。
- 极简操作：常用动作尽量交给鼠标和少量快捷键。
- 支持拖放：把图片文件拖到窗口里即可打开。
- 支持命令行打开：也可以把图片路径作为启动参数传入。

## 打开图片

- 按 `Ctrl+O` 选择图片。
- 将图片文件直接拖入窗口。
- 也可以把图片路径作为启动参数传入。

支持的常见格式包括：BMP、DIB、GIF、ICO、JPG/JPEG/JPE、PNG、TIF/TIFF、WebP。

## 操作

| 操作 | 说明 |
| --- | --- |
| 鼠标滚轮 | 以鼠标所在位置为中心缩放图片 |
| 鼠标左键拖动图片 | 平移图片 |
| `R` | 顺时针旋转 90 度 |
| 按住 `R` 再按住鼠标左键拖动 | 自由旋转图片 |
| `H` | 水平翻转图片 |
| `V` | 垂直翻转图片 |
| `←` / `→` | 切换到同一文件夹中的上一张 / 下一张图片 |

窗口右上角提供置顶、最小化、最大化/还原和关闭按钮。置顶适合在参考图片、临摹、对照查看时使用。

## 配置

ImgViewer 会在程序目录旁保存 `imgviewer.jsonc`。将 `pixelatedSampling` 设为 `true` 后，放大图片时会使用像素化采样，适合查看像素图、图标和纹理细节；默认值为 `false`，保持平滑缩放。
