# ImgViewer

Tung's ImgViewer 是一个轻量、快速、极简主义的，面向 Windows 10/11 的图片查看器。

## 特点

可以在官网查看 ImgViewer 的种种特性。

- 现代的、适配了高分辨率和 HDR 的极简界面。
- 小而轻。原生 Win32 C++ 应用。< 5 MB。不需要安装各种版本的 Framework。
- 即便打开 10000 * 10000 的大图，也快得像闪电一样。
- 可配置。内建了多套热键，适配你的工作流，避免可能的热键冲突。
- 预览你的 PSD 文档。
- GIF/APNG/AWebP 动画也同样支持。可以逐帧查看。
- 快速查看剪贴板图像。
- 可以用方向键浏览同一文件夹中的上一张或下一张图片。因为正确实现了 Windows Shell Verb，它可以像旧的照片查看器一样，了解你在 Windows 资源管理器中如何排布文件。了解更多。
- 附带截图功能和简单编辑功能：旋转、裁切、标注、文本。（仅支持保存为静态 PNG 格式。）

## 默认操作

| 操作 | 说明 |
| --- | --- |
| 鼠标滚轮 | 以鼠标所在位置为中心缩放图片 |
| 鼠标左键拖动图片 | 平移图片 |
| `R` | 顺时针旋转 90 度 |
| 按住 `R` 再按住鼠标左键拖动 | 自由旋转图片 |
| `H` | 水平翻转图片 |
| `V` | 垂直翻转图片 |
| `←` / `→` | 切换到同一文件夹中的上一张 / 下一张图片 |

窗口右上角提供置顶、最小化、最大化/还原和关闭按钮。置顶适合在参考图片、临摹、对照查看时使用。

## 配置

ImgViewer 会在程序目录旁保存 `imgviewer.config.js`，格式为 `globalThis.imgviewerConfig = { ... };`。将 `pixelatedSampling` 设为 `true` 后，放大图片时会使用像素化采样，适合查看像素图、图标和纹理细节；默认值为 `false`，保持平滑缩放。将 `borderlessWindow` 设为 `true` 后，主窗口会禁用原生边框和阴影；鼠标离开窗口时只显示图片，鼠标进入后恢复工具栏。
